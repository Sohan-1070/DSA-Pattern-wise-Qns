# DSA Pattern-wise Questions

We have created a pattern wise DSA repo for students to practise 28 patterns in both JAVA and Python.

This repository contains solutions to Data Structures and Algorithms (DSA) questions, organized by patterns.

## Patterns Included:
1. Two Pointers
2. Fast & Slow pointers
3. Sliding Window
4. Kadane pattern
5. PREFIX SUM
6. Merge Intervals
7. In-place Reversal of a LinkedList
8. Stack
9. Hash Maps
10. Binary Search
11. Heap Pattern
    - Kth
    - K closest
    - Heap as pointer
    - GREEDY+heap
    - 2 heaps
12. Recursion and Backtracking
13. Tree Pattern
    - Traversal
    - Mirror and Symmetry
    - Search
    - Validation
    - Path SUM
    - Construction
14. GRAPHS
15. DP (Dynamic Programming) - Episode 1

## Language Support:
- Java
- Python
